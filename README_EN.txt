PROJECT: VÂNIA DELIVERY LOGISTICS
Technologies: HTML5, CSS3, and JavaScript
Author: Vânia

HOW TO OPEN
1. Extract the Vania_Logistics_Delivery folder.
2. Open the folder in Visual Studio Code.
3. Open index.html in your browser. For a better experience, use the Live Server extension.
4. Click "JS Program" to open the calculator in a new tab.
5. The calculator asks for the user's name when it opens and displays the current date and time.

PAGES
- index.html: home page
- sobre.html: about the concept and values
- servicos.html: services and calculation rules
- contacto.html: contact form with Send and Clear buttons
- programa-js.html: JavaScript welcome message and order calculator
- css/style.css: website styling
- js/main.js: responsive menu and demonstration form validation
- js/programa.js: welcome message, calculation, and receipt
- images/: custom illustrations and favicon

IMPLEMENTED JS PROGRAM RULES
- Up to four products.
- Product subtotal = unit price × quantity.
- 5% discount when the total quantity is greater than 15 units.
- 10% discount when the total quantity is greater than 30 units.
- Weight-based shipping = total weight of all units × 250 MT/kg.
- Continent fee: Africa/Asia = 1,000 MT; Europe = 2,000 MT; America/rest of the world = 3,000 MT.
- Total = subtotal - discount + weight-based shipping + continent fee.
